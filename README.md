# Wellbeing App

A mobile wellbeing app designed to help students build confidence and self-esteem, built as my IB Computer Science Internal Assessment.

## The problem

Many students struggle with self-confidence, motivation and social interaction, but aren't comfortable with traditional therapy or can't afford it. Most existing support platforms require payment, leaving these students with no accessible option.

## The process

I started by interviewing students to understand what they were struggling with and what kind of support they would actually use. Their answers shaped the app's features and a set of success criteria the final product was measured against.

## Features

- Account registration and login with data validation
- An onboarding quiz that personalizes exercises to each user
- A daily routine of activities to build confidence
- A notes section to track struggles and achievements
- A daily motivational quote
- Games to reduce stress
- A chat feature to connect with others facing similar challenges
- A rewards system to keep users motivated

## Built with

- JavaScript
- code.org App Lab
